# 1：仮のアイコン・ファビコンを正式な画像に差し替える

- 番号：1
- 親：なし
- 状態：未着手

生成したときの仮の画像（頭文字と枠だけのもの）を、本番へ公開する前に正式な画像へ差し替える。

## 差し替えるファイル

同じファイル名・同じ大きさで置き換える。

| ファイル | 大きさ |
| --- | --- |
| `public/favicon.ico` | 32×32 |
| `public/favicon.svg` | 縦横の比が1：1 |
| `public/apple-touch-icon.png` | 180×180 |
| `public/icons/icon-192.png` | 192×192 |
| `public/icons/icon-512.png` | 512×512 |

## 受け入れ条件

- AC-1：上のファイルが正式な画像に置き換わっている
- AC-2：`public/manifest.webmanifest` のアプリの名前が正しい
- AC-3：README の「仮のアイコン」の記載を消した
