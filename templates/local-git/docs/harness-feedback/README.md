# ハーネスの改善の提案の下書き

GitHub を使わないプロジェクトでは、ハーネス（`AGENTS.md`・Skill・テンプレート）の改善の提案を、このフォルダに下書きとして置きます。AIは、ハーネスのルール・Skill・テンプレートを自分で直さず、気づいた改善点をここに書くだけにします。利用者が内容を確かめて、ハーネスのリポジトリに伝えます。

## 書き方

- ファイル名：`<日付>-<内容>.md`（例：`2026-01-31-skill-unclear.md`）
- 見出しと内容は、次のとおり。プロジェクト固有の機密・秘密情報・個人情報は書かず、事象を一般化して書く

```
# [harness-feedback] <題名>

## 事象
何が起きたか

## 種類
ルールの食い違い／ルールに従った結果の手戻り／ルールの不足／分かりにくい書き方／動かない手順／生成されたファイルがおかしい／その他

## 関係するルール・ファイル
例：AGENTS.md の「作業の流れ」

## 起きた場面
どの作業の、どの工程で起きたか

## 影響
手戻りの大きさ、起きうる不具合など

## 改善の案
どう直すとよいか。案がなければ「なし」

## 急ぎかどうか
急ぎ／通常

## ハーネスのバージョン
.harness/config.yaml に記録されているバージョン
```

## 伝えたあと

利用者がハーネスのリポジトリに伝えたら、下書きのファイルの先頭に「伝えた日」を書き足します。
