# プロトタイプ

要件定義書（`docs/requirements.md`）の合意の後、Issue への分割の前に、画面の動きを確かめるためのもの。

- HTML・CSS・JavaScript だけで作る。ビルドの道具・フレームワーク・外部のライブラリは使わない。`index.html` をブラウザで開くだけで動く
- バックエンドには接続しない。データは `app.js` の中の架空のデータ（`testuser_001`・`@example.com` 等）で再現し、操作による変化はブラウザの中だけで保持する
- 秘密情報・本物の API キー・実在の個人情報を含めない
- 画面ごとに、読み込み中・データあり・データなし・エラーの表示と、操作の後に再読み込みせずに表示が変わることを再現する
- 使い捨てのもの。本番のコード（`frontend/`）に流用しない。確かめた記録としてコミットする

今あるファイルは、状態の切り替え方を示す見本である。洗い出した画面に合わせて書き換える。
